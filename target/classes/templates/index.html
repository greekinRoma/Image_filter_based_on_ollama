快速开始

1. 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh
2. 下载视觉模型 (推荐)
ollama pull llava:13b        # LLaVA 视觉模型
ollama pull minicpm-v:latest  # MiniCPM-V 视觉模型
ollama pull llama3.2-vision   # Llama 3.2 视觉模型
3. 启动本应用
./mvnw spring-boot:run

或者：

mvn spring-boot:run -Dspring-boot.run.arguments="--app.image-dir=./img"
4. 访问

打开浏览器访问 http://localhost:8080

使用流程

  1. 连接测试 — 在「单张分析」页点击"测试 Ollama 连接"
  2. 扫描图片 — 点击"扫描图片目录"载入图片列表
  3. 选择提示词 — 从预设中选择或输入自定义提示词
  4. 分析 — 单张分析或批量处理
  5. 筛选导出 — 在「结果浏览」页按类别筛选并导出 CSV

提示词技巧

  • 要求模型以 ONLY one word 回答，便于分类筛选
  • 自定义提示词选项允许自由输入任意提示词
  • 提示词可使用中文或英文，取决于所选模型

文件说明

  • img/ — 图片目录（通过 app.image-dir 配置）
  • filter_results/ — 导出 CSV 的保存目录
